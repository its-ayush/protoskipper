# IEC 61850 Driver

ProtoSkipper's built-in IEC 61850 plugin provides MMS client sessions,
GOOSE subscriber/publisher, Sampled Values decoding, SCL/SCD management,
PCAP dissection, a conformance test runner, and a substation overview panel.

## 1. Quick start

```bash
# Install the plugin (includes pyiec61850 binding)
pip install "protoskipper[iec61850]"

# GUI
protoskipper-gui

# CLI: run a scripting session against an IED
protoskipper run examples/iec61850_browse.py --host 192.168.1.100
```

`examples/iec61850_browse.py`:

```python
session = iec61850.Session(argv[0])
session.connect()
for ld in session.get_server_directory():
    print("LD:", ld)
session.close()
```

## 3. GUI features

### MMS object browser

After connecting, the **Object Browser** panel shows the IED's data model as a
tree.  Each node represents a logical device, logical node, data object, or
data attribute.  Right-clicking any leaf opens a context menu to read or write
(if write-protection permits).

### GOOSE subscription panel

The **GOOSE** panel lists all active subscriptions configured from the SCD
file.  Each row shows the control-block reference, the last received `stNum`,
`sqNum`, allData values, and a colour-coded health indicator.

### Sampled Values scope panel

The **SV Scope** panel renders a real-time waveform for each ASDU channel.
Pan/zoom controls and a "freeze" button are provided.  Recording to COMTRADE
is started from the **File → Export → COMTRADE** menu item.

### Substation overview panel

The **Substation Overview** tab shows a tile grid of all IEDs loaded from the
SCD file.  Each tile is colour-coded:

| Colour | Meaning |
|--------|---------|
| Green  | MMS online, GOOSE steady, SV present |
| Amber  | GOOSE late or SV gap; MMS may be online |
| Red    | MMS offline, or GOOSE alarm condition |

Tile positions and colours are persisted as a *bench layout* JSON file — see
[Bench layout format](#8-bench-layout-format).

### PCAP analysis panel

Open a `.pcap` or `.pcapng` file via **File → Open PCAP**.  The panel
dissects GOOSE, SV, and MMS frames and displays them in a filterable table.
See [PCAP filter language](#7-pcap-filter-language).

### IED simulator wizard

**Tools → IED Simulator** opens a wizard that lets you define logical nodes,
data objects, and GOOSE/SV outputs.  The simulator publishes live data into the
local Ethernet interface and responds to MMS requests, making it useful for
testing without real hardware.

## 4. SCD / SCL management

```python
# Load an SCD file
doc = iec61850.Scd.parse("/path/to/substation.scd")

# Enumerate IEDs
for ied in doc.ieds:
    print(ied.name, ied.manufacturer, ied.type)

# Diff two SCD files
old = iec61850.Scd.parse("v1.scd")
new = iec61850.Scd.parse("v2.scd")
delta = iec61850.Scd.diff(old, new)
for change in delta.changes:
    print(change)
```

The built-in SCL editor (opened via **File → Open SCD**) supports syntax
highlighting, live validation against IEC 61850-6, and a diff view.

## 5. Conformance testing

### Running tests from a script

```python
from protoskipper_iec61850.conformance.schema import load_builtin_profile
from protoskipper_iec61850.conformance.runner import ConformanceRunner
from protoskipper_iec61850.conformance.reporter import write_html_report

profile = load_builtin_profile("mms_ed21")

runner = ConformanceRunner(
    profile,
    session_ctx={"mms_client": client},  # MmsClient instance
    operator="Alice Engineer",
    device_info={"firmware": "v2.3.1", "model": "IED-X100"},
    on_progress=lambda tc, r: print(tc.test_id, r.status.value),
)
report = runner.run()
write_html_report(report, "conformance_report.html", audit_sig="abc123")
print("Passed:", report.passed, "/", report.total)
```

### Built-in profiles

| Profile ID        | Scope            | Edition |
|-------------------|------------------|---------|
| `mms_ed21`        | MMS client       | 2.1     |
| `goose_pub_ed21`  | GOOSE publisher  | 2.1     |

### Custom profiles

Write a YAML file following this schema:

```yaml
profile_id: my_custom
edition: "2.1"
category: MMS
description: My custom test suite

tests:
  - id: TC_001
    name: "Initiate connection"
    description: "Verify MMS association is established."
    service: Initiate
    severity: MANDATORY        # MANDATORY | OPTIONAL | CONDITIONAL
    steps:
      - action: connect
        params:
          port: 102
      - action: assert_connection
        params:
          status: connected
```

Load with `ConformanceProfile.load_yaml(path)`.

### HTML / PDF reports

```python
from protoskipper_iec61850.conformance.reporter import (
    write_html_report,
    write_pdf_report,
)

write_html_report(report, "report.html")
write_pdf_report(report, "report.pdf")   # requires: pip install weasyprint
```

## 6. Scripting API

All IEC 61850 functionality is available in the `iec61850` namespace when
running `protoskipper run <script.py>`.

### Session — MMS client

```python
# Create and connect
session = iec61850.Session(
    host="192.168.1.100",
    port=102,
    connect_timeout_ms=10_000,
    allow_writes=False,      # default — reads only
)
session.connect()

# Or use as a context manager
with iec61850.Session("192.168.1.100", allow_writes=True) as s:
    s.write("IED1LD0/CSWI1.Pos.ctlVal", True, fc="CO")
```

**Key methods:**

| Method | Description |
|--------|-------------|
| `read(reference, fc="MX")` | Read one data attribute |
| `read_all(ld, ln, fc)` | Read all attributes of a logical node |
| `write(reference, value, fc="SP")` | Write (requires `allow_writes=True`) |
| `get_server_directory()` | List logical devices |
| `get_logical_device_directory(ld)` | List logical nodes in a device |
| `get_data_directory(ld, ln)` | List data objects in a node |
| `get_data_definition(ref, fc)` | Variable-access-attributes |
| `enable_reporting(rcb_ref, id, on_report=cb)` | Enable unbuffered RCB |
| `disable_reporting(rcb_ref)` | Disable RCB |
| `close()` | Close MMS association |

### Goose namespace

```python
# Subscribe to all GOOSE frames on an interface
svc = iec61850.Goose.Subscriber(interface="eth0")
svc.subscribe("IED1LD0/LLN0$GO$gcbEvents", on_message=lambda f: print(f))
svc.start()
# ... wait ...
svc.stop()

# Publish a GOOSE frame
pub = iec61850.Goose.Publisher(interface="eth0")
pub.start(go_cb_ref="IED1LD0/LLN0$GO$gcbEvents", data_set_ref="IED1LD0/LLN0$Events")
pub.publish([True, 0x0042])
pub.stop()
```

### Sv namespace

```python
# Subscribe to SV frames
svc = iec61850.Sv.Subscriber(interface="eth0")
svc.subscribe(sv_id="TEMPLATE_SV", on_asdu=lambda asdu: print(asdu))
svc.start()

# Decode a raw captured frame
frame_bytes = b"..."
result = iec61850.Sv.decode_frame(frame_bytes)
if result:
    for asdu in result.asdus:
        print(asdu.sv_id, asdu.sample_count)
```

### Scd namespace

```python
doc = iec61850.Scd.parse("/path/to/substation.scd")
delta = iec61850.Scd.diff(doc_v1, doc_v2)
```

### dissect namespace

```python
from protoskipper_iec61850.dissect.pcap import PcapReader
from protoskipper_iec61850.dissect.goose import decode_goose_frame
from protoskipper_iec61850.dissect.filter_lang import compile_filter

filt = compile_filter("goose.stnum > 0 and goose.gocbref ~= 'Events'")

with PcapReader("/tmp/capture.pcap") as reader:
    for record in reader:
        g = decode_goose_frame(record.data)
        if g and filt.match({"goose": g}):
            print(g.go_cb_ref, g.st_num, g.all_data)
```

### conformance namespace

```python
from protoskipper_iec61850.conformance.schema import load_builtin_profile
from protoskipper_iec61850.conformance.runner import ConformanceRunner

profile = load_builtin_profile("mms_ed21")
runner = ConformanceRunner(profile, session_ctx={"mms_client": mms})
report = runner.run()
print(report.overall_pass)
```

## 7. PCAP filter language

The filter language is a simple expression language for matching dissected
packets. Syntax: `PROTO.ATTR OP value` combined with `and`, `or`, `not`, and
parentheses.

### Protocols

| Prefix   | Dissector |
|----------|-----------|
| `goose`  | GOOSE Ethernet frame |
| `sv`     | Sampled Values frame |
| `mms`    | MMS PDU (from TCP) |

### Attribute names

**GOOSE:** `gocbref`, `goid`, `dataset`, `stnum`, `sqnum`, `confrev`, `test`,
`ndsc`, `appid`, `srcmac`, `dstmac`, `vlanid`

**SV:** `svid`, `appid`, `noasdu`, `srcmac`, `dstmac`, `vlanid`

**MMS:** `pdutype`, `invokeid`, `service`

### Operators

| Operator | Meaning |
|----------|---------|
| `=`, `==` | Equality |
| `!=`, `<>` | Inequality |
| `<`, `<=`, `>`, `>=` | Numeric comparison |
| `~=` | Regex match (re.search) |

### Examples

```
goose.stnum > 0 and goose.gocbref ~= "Events"
sv.noasdu >= 1 and sv.svid = "TEMPLATE_SV"
mms.service = "Read" or mms.service = "GetNameList"
not goose.test
```

## 8. Bench layout format

The Substation Overview panel saves tile positions as JSON:

```json
{
  "version": 1,
  "scd_path": "/path/to/substation.scd",
  "tiles": [
    {
      "ied_name": "IED_MERGING1",
      "x": 0,
      "y": 0,
      "colour": "#2266aa",
      "expected_goose_refs": ["IED_MERGING1LD0/LLN0$GO$gcbEvents"],
      "notes": "Bay 1 merging unit"
    }
  ]
}
```

Load/save from the GUI via **File → Save Layout** / **File → Open Layout**, or
programmatically:

```python
from protoskipper_iec61850.bench_layout import load_bench_layout, save_bench_layout
layout = load_bench_layout("/path/to/layout.json")
save_bench_layout(layout, "/path/to/layout.json")
```

## 9. Safety and write-protection

All IEC 61850 sessions created from `protoskipper run <script>` have
`allow_writes=False` by default.  To enable writes, pass `--allow-writes` to
the CLI or explicitly create the session with `allow_writes=True`.

Direct MMS control operations (`Pos.ctlVal`, `CSWI`) open a
**GuiConfirmHandler** dialog that blocks for up to 300 seconds.  If the
operator denies or the timeout expires, the write is rejected.  This is
enforced at the `DriverWorker` level and cannot be bypassed by scripts.

## 10. Protocol primer

### MMS (Manufacturing Message Specification)

MMS is an ISO 9506 application-layer protocol for industrial automation.
IEC 61850-8-1 maps the IEC 61850 data model onto MMS services over TCP/IP
(port 102, TPKT + ISO COTP + ISO session/presentation layers).

Key services used by ProtoSkipper: `Initiate`, `GetNameList`, `Read`,
`Write`, `GetVariableAccessAttributes`, `EnableJournal`, `Conclude`.

### GOOSE (Generic Object Oriented Substation Event)

GOOSE is a multicast Ethernet service (EtherType `0x88B8`) for fast binary
and analogue status exchange between IEDs.  It uses publisher-subscriber with
a repetition algorithm: on state change, the frame is retransmitted at
decreasing intervals until steady-state.

Key fields: `goCBRef`, `goID`, `datSet`, `stNum`, `sqNum`, `t` (timestamp),
`allData`.

### Sampled Values (SV)

SV (EtherType `0x88BA`) carries digitised current/voltage samples from
merging units to protection relays.  Each frame contains one or more ASDUs
(Application Service Data Units) with configurable sample rate (typically
80 or 256 samples/cycle at 50/60 Hz).

## 11. Troubleshooting

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| `ImportError: pyiec61850` | C binding not installed | `pip install pyiec61850` |
| GOOSE tiles all red | Wrong network interface | Set correct interface in Preferences → IEC 61850 |
| MMS connect timeout | Firewall blocking port 102 | Check ACSE/COTP/MMS stack on IED |
| `WeasyPrint not installed` on PDF export | weasyprint missing | `pip install weasyprint` |
| SCD parse error | File encoding or namespace | Ensure UTF-8, correct IEC 61850-6 namespace |
