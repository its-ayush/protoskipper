# Internationalisation (i18n) Guide

ProtoSkipper uses Qt's standard `tr()` / `QTranslator` mechanism for UI strings.
All user-facing strings in the GUI layer are wrapped with `self.tr("…")` or
`QCoreApplication.translate("Context", "…")` so they can be extracted and
translated without code changes.

---

## Workflow

### 1. Extract translatable strings

From the repository root, run `pyside6-lupdate` against all Python source files
to regenerate the `.ts` (translation source) catalog:

```bash
pyside6-lupdate -python src/protoskipper/gui/**/*.py \
                -ts translations/protoskipper_en.ts
```

> **Tip:** `pyside6-lupdate` is bundled with the `PySide6` pip package.

### 2. Translate

Open the generated `.ts` file in **Qt Linguist** (`pyside6-linguist`) or a
compatible editor, translate the strings, and mark them as *finished*.

Save the updated `.ts` file back to `translations/`.

### 3. Compile to binary

```bash
pyside6-lrelease translations/protoskipper_<locale>.ts \
               -qm translations/protoskipper_<locale>.qm
```

### 4. Install and load at runtime

Place compiled `.qm` files in a `translations/` directory that ships with the
package (add it to `MANIFEST.in` / `pyproject.toml` `[tool.setuptools.package-data]`).

In `app.py`, install the translator before constructing `MainWindow`:

```python
from PySide6.QtCore import QTranslator, QLocale, QLibraryInfo
translator = QTranslator()
locale = QLocale.system().name()           # e.g. "fr_FR"
if translator.load(f"translations/protoskipper_{locale}.qm"):
    app.installTranslator(translator)
```

---

## File conventions

| Path | Purpose |
|------|---------|
| `translations/protoskipper_en.ts` | English source catalog (committed) |
| `translations/protoskipper_<locale>.ts` | Per-locale translation file (committed) |
| `translations/protoskipper_<locale>.qm` | Compiled binary (generated, gitignored) |

---

## Rules for contributors

1. **Wrap every new user-visible string** in `self.tr("…")` inside Qt widget
   subclasses, or in `QCoreApplication.translate("ClassName", "…")` in module-
   level helpers.
2. **Do not translate log messages** — these stay in English for searchability.
3. **Do not concatenate translated fragments** — use Python format strings with
   named placeholders so word order can differ across languages:
   ```python
   self.tr("Connected to {address} ({profile})").format(
       address=addr, profile=profile_name
   )
   ```
4. Re-run `pyside6-lupdate` and commit the updated `.ts` file whenever strings
   are added or changed.
