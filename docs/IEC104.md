# IEC 60870-5-104 Driver

ProtoSkipper's built-in IEC 104 driver provides both a **master** (client)
and a **slave** (server) implementation of the IEC 60870-5-104 protocol
suitable for testing, commissioning, and analysis of SCADA/BMS systems.

## 1. Quick start

```bash
pip install "protoskipper[iec104]"

# GUI
protoskipper-gui

# CLI: connect and perform a General Interrogation
protoskipper run examples/iec104_gi.py --host 192.168.1.100
```

`examples/iec104_gi.py`:

```python
# Allow read-only commands; no --allow-writes needed for GI
master = iec104.MasterSession(argv[0])
with master:
    asdus = master.gi()
    for asdu in asdus:
        log.info("%s", asdu)
```

## 2. GUI — connecting to a slave

1. **File → New connection** (or `Ctrl+N`).
2. In the *Protocol* dropdown, select **IEC 60870-5-104**.
3. Enter the **Host** and **Port** (default 2404).
4. Optionally expand *Advanced* to set the Common Address (CA), T0–T3
   timers, K/W window sizes, or a TLS client certificate.
5. Click **Connect**.

The session appears in the **Device Tree** panel. A single IEC 104 session
exposes one virtual device whose data objects are the live ASDU data items.

The **Object Browser** shows every IOA seen since the last General
Interrogation. Click **GI** in the toolbar to re-trigger interrogation.

The **Packet View** shows the raw APDU/ASDU stream with decoded fields.
Right-click a row to copy the raw hex or open the frame in the detail pane.

Write operations (single command, set-point, etc.) are available in the
**Watchlist** panel. Drag an IOA from the Object Browser into the watchlist,
then click the pencil icon. The confirmation dialog and audit log apply to
all writes — see §7.

## 3. Scripting API

The scripting façade lives at `protoskipper.builtin_drivers.iec104.scripting`
and is injected as the `iec104` binding in `protoskipper run` scripts and
the GUI Python REPL console.

```python
# In a protoskipper run script the iec104 object is already bound:
master = iec104.MasterSession("10.0.0.1")
```

### MasterSession

```python
class MasterSession(
    host: str,
    port: int = 2404,
    *,
    ca: int = 1,
    originator: int = 0,
    k: int = 12,
    w: int = 8,
    t0: float = 30.0,
    t1: float = 15.0,
    t2: float = 10.0,
    t3: float = 20.0,
    auto_reconnect: bool = True,
    reconnect_delay: float = 5.0,
    tls: bool = False,
    tls_context: ssl.SSLContext | None = None,
    allow_writes: bool = False,
    confirm: Callable[[str], bool] | None = None,
)
```

| Method | Description |
|--------|-------------|
| `connect()` | Open the TCP connection and start the APCI state machine. |
| `close()` | Send STOPDT, close socket. |
| `gi(group=20, *, timeout=None)` | General Interrogation. Returns `list[Asdu]`. |
| `ci(group=37, freeze=1, *, timeout=None)` | Counter Interrogation. Returns `list[Asdu]`. |
| `read(ioa, *, timeout=None)` | Read a single point (C_RD_NA_1). Returns `Asdu`. |
| `clock_sync(ts=None, *, timeout=None)` | Send C_CS_NA_1. Requires `allow_writes=True`. |
| `command(ioa, type_id, *, value, on, qu, select_execute, timeout)` | Generic command. See below. |
| `subscribe(callback)` | Register a `Callable[[Asdu], None]` for spontaneous data. |

`MasterSession` is a context manager: `connect()` on enter, `close()` on exit.

#### command()

```python
def command(
    self,
    ioa: int,
    type_id: str | int | TypeID,  # e.g. "C_SC_NA_1", 45, TypeID.C_SC_NA_1
    *,
    value: Any = None,       # setpoint / DCO integer
    on: bool | None = None,  # convenience for C_SC_NA_1 / C_DC_NA_1
    qu: int = 0,             # Qualifier of Command
    select_execute: bool = False,   # Select-Before-Operate
    timeout: float | None = None,
) -> list[Asdu]
```

Supported type IDs: `C_SC_NA_1` (45), `C_DC_NA_1` (46),
`C_SE_NA_1` (48), `C_SE_NB_1` (49), `C_SE_NC_1` (50).

Requires `allow_writes=True` (pass `--allow-writes` on the CLI, or construct
`MasterSession(..., allow_writes=True)` in a script).

#### Example — single command with SBO

```python
with iec104.MasterSession("10.0.0.1", allow_writes=True) as master:
    master.gi()
    # Select-before-execute: trip breaker at IOA 101
    replies = master.command(101, "C_SC_NA_1", on=True, select_execute=True)
    for r in replies:
        log.info("Response: %s  COT=%s", r.type_id, r.cot)
```

### SlaveServer

Simulate an IEC 104 outstation (slave / RTU) for testing master software.

```python
class SlaveServer(
    host: str = "0.0.0.0",
    port: int = 2404,
    *,
    ca: int = 1,
    k: int = 12,
    w: int = 8,
    t1: float = 15.0,
    t2: float = 10.0,
    t3: float = 20.0,
    sbo_timeout: float = 10.0,
    backlog: int = 5,
    max_clients: int = 10,
    tls: bool = False,
    tls_context: ssl.SSLContext | None = None,
    allow_in_production: bool = False,
)
```

| Method | Description |
|--------|-------------|
| `add_points(points)` | Register `list[SlavePoint]` before starting. |
| `inject(ioa, type_id, value, *, quality, timestamp)` | Add or update a point. If running, broadcasts spontaneous ASDU to all connected masters. |
| `set_command_handler(handler)` | Supply a `Callable[[Asdu], bool \| None]`. Return `True` to accept, `False` to reject, `None` for default. |
| `start()` | Bind socket and begin accepting connections. |
| `stop()` | Disconnect all clients and close socket. |
| `.port` | Actual bound port (useful when `port=0` was passed for OS assignment). |

`SlaveServer` is a context manager: `start()` on enter, `stop()` on exit.

> **Safety guard:** `start()` raises `RuntimeError` when
> `PROTOSKIPPER_PROFILE=PRODUCTION` unless `allow_in_production=True`.
> The scripting namespace supplied by `protoskipper run` wraps
> `SlaveServer` to enforce `--allow-writes` at the boundary.

#### Example — simple slave

```python
from protoskipper.builtin_drivers.iec104.asdu import SlavePoint, TypeID, Quality

points = [
    SlavePoint(ioa=1, type_id=TypeID.M_SP_NA_1, value=False, quality=Quality()),
    SlavePoint(ioa=100, type_id=TypeID.M_ME_NC_1, value=3.14, quality=Quality()),
]

with iec104.SlaveServer(port=2404, allow_in_production=True) as srv:
    srv.add_points(points)
    # Update a point while running — connected masters receive SPONT ASDU
    import time
    for i in range(10):
        time.sleep(1)
        srv.inject(100, TypeID.M_ME_NC_1, float(i))
```

### PcapReader

Replay and analyse captured IEC 104 traffic from a `.pcap` file.

```python
class PcapReader(path: str | Path, *, iec104_port: int = 2404)
```

`PcapReader` is iterable and yields `DissectedFrame` objects:

```python
for frame in iec104.PcapReader("capture.pcap"):
    print(frame.timestamp, frame.src_ip, frame.apdu)
```

#### DissectedFrame

| Field | Type | Description |
|-------|------|-------------|
| `timestamp` | `float` | Unix epoch |
| `src_ip` | `str` | Source IP |
| `src_port` | `int` | Source port |
| `dst_ip` | `str` | Destination IP |
| `dst_port` | `int` | Destination port |
| `apdu` | `Apdu` | Decoded APDU (I/S/U frame) |
| `raw_bytes` | `bytes` | Raw APDU bytes |

#### PcapReader.summarize(path)

```python
summary = iec104.PcapReader.summarize("capture.pcap")
# → {"I": 452, "S": 103, "U": 8, "total": 563, "errors": 0}
```

### Fuzzer

Static methods for fuzzing the IEC 104 codec and a live target.

```python
iec104.Fuzzer.codec_roundtrip(iterations=5000, seed=0)  → FuzzReport
iec104.Fuzzer.asdu_codec(iterations=5000, seed=0)        → FuzzReport
iec104.Fuzzer.apdu_mutation(iterations=5000, seed=0)     → FuzzReport
iec104.Fuzzer.against_target(host, port, iterations=200, seed=0, connect_timeout=5.0)
                                                          → StateMachineReport
```

#### FuzzReport

| Field | Type | Description |
|-------|------|-------------|
| `iterations` | `int` | Number of fuzz rounds |
| `valid_decodes` | `int` | Successful round-trips |
| `expected_errors` | `int` | Errors that are expected codec rejections |
| `unexpected_errors` | `int` | Errors indicating a potential codec bug |
| `seed` | `int` | RNG seed used |
| `.ok` | `bool` | `True` when `unexpected_errors == 0` |

#### StateMachineReport

| Field | Type | Description |
|-------|------|-------------|
| `sent` | `int` | APDUs sent |
| `peer_closed` | `bool` | Whether the server closed the connection |
| `duration_seconds` | `float` | Elapsed time |
| `seed` | `int` | RNG seed used |

## 4. CLI

```bash
# List all registered protocol drivers
protoskipper list-protocols

# Run a script with read-only access (default)
protoskipper run my_script.py -- 192.168.1.100

# Run a script that issues write commands
protoskipper run my_script.py --allow-writes -- 192.168.1.100

# Scan a subnet for IEC 104 devices (future: planned for P4.D)
# protoskipper scan iec104 192.168.1.0/24
```

Inside a script, the `iec104` object is injected automatically.
The `argv` list contains extra positional arguments after `--`.

```python
# my_script.py
host = argv[0]
port = int(argv[1]) if len(argv) > 1 else 2404

with iec104.MasterSession(host, port) as master:
    results = master.gi()
    log.info("Received %d ASDUs from GI", len(results))
```

## 5. PCAP analysis

```bash
# Summarise a capture
python - <<'EOF'
import sys
from protoskipper.builtin_drivers.iec104 import PcapReader
print(PcapReader.summarize(sys.argv[1]))
EOF capture.pcap

# Decode every frame
python - <<'EOF'
import sys
from protoskipper.builtin_drivers.iec104 import PcapReader
for frame in PcapReader(sys.argv[1]):
    print(f"{frame.timestamp:.3f}  {frame.src_ip}:{frame.src_port} → "
          f"{frame.dst_ip}:{frame.dst_port}  {frame.apdu}")
EOF capture.pcap
```

## 6. Fuzzing

> **Warning:** `Fuzzer.against_target()` sends malformed APDUs to a live
> host. **Never run this against production infrastructure.**

```python
# Offline codec fuzz — safe, no network traffic
report = iec104.Fuzzer.codec_roundtrip(iterations=10_000, seed=42)
print(report.ok, report.unexpected_errors)

# Network fuzz against a test slave
report = iec104.Fuzzer.against_target("127.0.0.1", 2404, iterations=500)
print(f"Sent {report.sent} APDUs; peer_closed={report.peer_closed}")
```

## 7. Safety and write-protection

ProtoSkipper enforces a two-layer write protection model:

| Layer | Mechanism |
|-------|-----------|
| **CLI** | `--allow-writes` flag must be passed to `protoskipper run`. Without it, `iec104.MasterSession` is configured with `allow_writes=False` and raises `PermissionError` on any command attempt. |
| **GUI** | The session's `SafetyContext` profile (LAB / COMMISSIONING / PRODUCTION) controls what the `DriverWorker` permits. A `GuiConfirmHandler` prompts the operator for each write with a 300-second timeout (default deny). |

The scripting REPL in the GUI always has `allow_writes=True` because the
`SessionManager` and `SafetyContext` enforce safety at the session level.

All writes — successful or rejected — are recorded in the HMAC-chained
SQLite audit log (see `core/audit.py`).

## 8. TLS

IEC 104 with TLS (per IEC 62351-3) is supported.

```python
import ssl

ctx = ssl.create_default_context(ssl.Purpose.SERVER_AUTH, cafile="ca.pem")
ctx.load_cert_chain("client.pem", "client.key")

with iec104.MasterSession("10.0.0.1", tls=True, tls_context=ctx) as master:
    master.gi()
```

For the slave:

```python
import ssl

ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_SERVER)
ctx.load_cert_chain("server.pem", "server.key")
ctx.load_verify_locations("ca.pem")
ctx.verify_mode = ssl.CERT_REQUIRED

with iec104.SlaveServer(tls=True, tls_context=ctx, allow_in_production=True) as srv:
    ...
```

In the GUI, supply the certificate paths in the *Advanced* section of the
New Connection dialog.

## 10. Protocol primer

IEC 60870-5-104 is a telecontrol companion standard that carries the
IEC 60870-5-101 application layer over TCP/IP.

### APCI / APDU structure

```
+-------+--------+--------+--------+--------+--------+
| 0x68  | Length | Ctrl1  | Ctrl2  | Ctrl3  | Ctrl4  |
+-------+--------+--------+--------+--------+--------+
| [ASDU payload …]                                   |
+----------------------------------------------------+
```

The start byte is always `0x68`.  Four **frame types**:

| Type | Name | Purpose |
|------|------|---------|
| I | Information | Carries an ASDU (data transfer) |
| S | Supervisory | Acknowledgement only |
| U | Unnumbered | Control (STARTDT, STOPDT, TESTFR) |

### ASDU structure

```
Type ID (1 byte) | VSQ (1 byte) | COT (2 bytes) | CA (2 bytes)
[ IOA (3 bytes) | Information Object … ] × n
```

**Key Type IDs:**

| Type ID | Value | Direction | Description |
|---------|-------|-----------|-------------|
| M_SP_NA_1 | 1 | M→C | Single-point information |
| M_DP_NA_1 | 3 | M→C | Double-point information |
| M_ME_NA_1 | 9 | M→C | Measured normalised value |
| M_ME_NB_1 | 11 | M→C | Measured scaled value |
| M_ME_NC_1 | 13 | M→C | Measured short float |
| M_IT_NA_1 | 15 | M→C | Integrated totals |
| C_SC_NA_1 | 45 | C→M | Single command |
| C_DC_NA_1 | 46 | C→M | Double command |
| C_SE_NA_1 | 48 | C→M | Set-point (normalised) |
| C_SE_NB_1 | 49 | C→M | Set-point (scaled) |
| C_SE_NC_1 | 50 | C→M | Set-point (short float) |
| C_IC_NA_1 | 100 | C→M | Interrogation command (GI) |
| C_CI_NA_1 | 101 | C→M | Counter interrogation |
| C_CS_NA_1 | 103 | C→M | Clock synchronisation |

### Connection lifecycle

```
Master                          Slave
  |                               |
  |----TCP SYN------------------->|
  |<---TCP SYN-ACK----------------|
  |----STARTDT act--------------->|
  |<---STARTDT con----------------|
  |     (data transfer phase)     |
  |----C_IC_NA_1 (GI)------------>|
  |<---M_SP_NA_1 … (GI data)------|
  |<---C_IC_NA_1 ACTTERM----------|
  |----STOPDT act---------------->|
  |<---STOPDT con-----------------|
  |----TCP FIN------------------->|
```

For full protocol details see IEC 60870-5-104:2006 and the companion
standard IEC 60870-5-101.
